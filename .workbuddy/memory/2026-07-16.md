- Left teal `>` chevron = platform endpoint
- Right indigo `<` chevron = agent endpoint
- Horizontal ink bridge line + center diamond = protocol handshake node
- Reads as code brackets / message envelope — much more dev/tech-native
- All variants rebuilt: 140/96/48 + MONO + REVERSED
- Layout verified clean (zero issues)

## v3 (presented): Two additional concepts for comparison

### 方案 C — 电路节点 (Circuit Node / PCB Trace)
- Teal left pad + indigo right pad = platform & agent endpoints
- Stepped orthogonal trace (PCB dogbone) connecting them, ink stroke
- Center via circle at step apex = protocol node
- Infra/infrastructure vibe — reads like a circuit board routing

### 方案 D — NDJSON 流线 (Stream Lines / Terminal)
- Ink cursor block (leading) + 3 horizontal log lines of varying length
- Line colors: indigo (longest) → teal → ink
- Terminal caret triangle at end of last line
- Dev/terminal vibe — reads like streaming NDJSON event output

Both presented as lockups (mark 96px + wordmark 64px) in Alternatives section of brand sheet.
Layout verified clean (zero issues). **Awaiting user selection.**
